## Discord

Discord is the heart of the Cyberwave community. It's where new features get announced first, where the team shares work-in-progress demos, and where most real-time troubleshooting happens. You'll find channels organized by topic — hardware-specific help, simulation, ML pipelines, and general building — so you can jump straight to the right crowd. The team monitors Discord every day and typically responds within a few hours. If you have a question, this is almost always the fastest path to an answer.

[Join the Cyberwave Discord →](https://discord.gg/dfGhNrawyF)

## Built with Cyberwave

The Built with Cyberwave showcase is a living gallery of projects the community has shipped — from autonomous inspection drones to robotic arm demonstrations trained entirely through imitation learning. It's a great place to browse when you're looking for ideas, see how others have structured their pipelines, or find collaborators working on similar problems. When you ship something you're proud of, share it there. The best projects get featured in the Cyberwave newsletter and on social.

[Browse the showcase →](https://cyberwave.com/built-with-cyberwave)

## GitHub

All of Cyberwave's core tooling is open source and lives in the [cyberwave-os](https://github.com/cyberwave-os) GitHub organization: the Python SDK, the CLI, hardware drivers, edge runtime components, and community-contributed robot integrations. If you find a bug, open an issue. If you want to add support for a new robot, submit a pull request — the driver contribution guide is in the repo README. Open source is how Cyberwave's hardware catalog grew to 90+ devices, and every contribution makes the platform better for everyone.

[View the GitHub org →](https://github.com/cyberwave-os)

## Events & Hackathons

Cyberwave runs regular in-person and hybrid events where you can build alongside the core team, get hands-on time with real robot hardware, and meet other developers working on robotics and AI. Past events have ranged from weekend hackathons focused on imitation learning to workshops walking through full data-collection-to-deployment pipelines. Check the community page for upcoming events and registration links.

[See upcoming events →](https://cyberwave.com/community)

## Getting Help

<Note>
  **Discord first.** For questions, troubleshooting, and quick feedback, Discord is your best option — the team responds there faster than anywhere else.
</Note>

For **bugs and feature requests**, open an issue on GitHub. A written issue gives the team the context they need to reproduce problems and track them to resolution. When filing a bug, include your SDK version (`cyberwave --version`), the robot twin ID you're working with, and the full error output.

For **common setup questions**, check the [FAQ](/resources/faq) before posting — there's a good chance your question is already answered there.
