## What You Can Build

Cyberwave is designed for developers and AI builders who need to move fast without getting stuck in robotic infrastructure:

- **Connect any robot** — 90+ supported robots from DJI drones to Unitree robot dogs, all using the same `cw.twin()` call
- **Test safely in simulation** — run your code against a virtual twin in the browser (Playground) or in full-fidelity MuJoCo physics before touching real hardware
- **Swap controllers at runtime** — hand off between human keyboard control, your own Python code, and AI model controllers without stopping a session
- **Use AI out of the box** — drop any of 100+ catalog models (vision, VLA, pose, segmentation) onto a twin with a single line of code
- **Collect and train** — every twin is a data source; episodes go straight into training pipelines in open formats (LeRobot, parquet)

## How It Works

<Steps>
  <Step title="Create an account">
    [Sign up at cyberwave.com](https://cyberwave.com/register) and generate an API token from **Profile → API Tokens**.
  </Step>
  <Step title="Install the SDK">
    ```bash
    pip install cyberwave
    ```
  </Step>
  <Step title="Connect to a twin">
    ```python
    from cyberwave import Cyberwave

    cw = Cyberwave()  # reads CYBERWAVE_API_KEY from your environment
    drone = cw.twin("dji/dji-mini-4-pro")
    drone.takeoff()
    ```
  </Step>
  <Step title="Go from simulation to real hardware">
    Test in the Playground simulation, then pair your physical robot with `cyberwave pair` and flip to live mode — same code, same SDK.
  </Step>
</Steps>
